  1. 컴퓨터: 파일을 더블클릭하면 크롬·엣지·사파리에서 바로 실행됩니다.
  2. 아이폰·아이패드: 파일을 인터넷에 올린 주소(예: GitHub Pages, Netlify Drop)를 Safari에서 열면 실행됩니다.
